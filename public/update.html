If your existence is unable to update to the most recent patch, please first check to make sure
there is an update available and that you are successfully connected to the update servers.

If that is working fine, please go ahead and make sure the update executable has full
permissions enabled. This sometimes happens during interdimensional file transfers.
If needed you can try to run it in compatibility mode as well.

Should neither method work, you can always extract the files yourself and manually install it.
Please note that this is not recommended and is considered to be a hack.
